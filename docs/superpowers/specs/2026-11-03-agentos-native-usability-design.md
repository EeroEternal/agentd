# AgentOS Native 可用性改进设计

## 目标

在原生启动、网络和自主工作流已验证的基础上，修复本地控制台交互并完善服务停止顺序。保持当前原生系统、网络和 SSH 不变。

## 控制台

原生控制台直接绑定 `/dev/tty1`，不再使用当前的 agetty 启动方式。除取得控制 TTY 外，还必须：

- 将当前进程组设为 TTY 前台进程组；
- 将标准输入、输出和错误重定向到该 TTY；
- 开启 CR/LF 输入输出转换；
- 开启 `CREAD`、`ECHO`、`ECHOE`、`ECHOK`、`ICANON` 和 `ISIG`；
- 设置 `VMIN=1`、`VTIME=0`；
- 最后进入 root Bash 登录 shell。

该服务在下次原生启动时重新启用。网络仍由现有原生服务提供，因此控制台再次失败时可以远程禁用，不需要恢复系统。

## 服务停止顺序

原生监督器停止全部服务时，不再按名称逆序，而是按定义中的 `priority` 从高到低停止。这样高优先级应用先停止，udev、D-Bus、NetworkManager 和 resolved 等基础组件后停止。

## 验证

- Python 源码语法检查通过。
- 控制台服务定义为启用状态，argv 指向新的原生控制台。
- 下一次原生启动后，本地键盘能输入并显示字符，能执行命令。
- 网络和 SSH 在控制台启用后仍正常。
- 原所有启动项和默认项不变。
